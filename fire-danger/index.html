Wildfire Danger Index

The portal displays daily laboratory-produced GeoTIFF layers for wildfire danger monitoring. Supported products include Burning Index, Fire Weather Index, Wildland Fire Likelihood, and related operational fire danger metrics.

Data Update Notes

Daily GeoTIFF files are published from source/fire-danger-data/. After adding new files, run npm run data:update and rebuild the site.

Data Policy

Each raster layer should be accompanied by clear metadata: index name, production date, units, spatial extent, processing version, and contact point. For operational use, always check the timestamp and notes before making decisions.

Supported Products

  • BI: Burning Index.
  • FWI: Fire Weather Index.
  • WFL: Wildland Fire Likelihood.
  • ERC: Energy Release Component.
  • SC: Spread Component.
  • IC: Ignition Component.

Additional products can be added by placing GeoTIFF files in the data directory and including the desired indexId in either the file name or sidecar metadata. Recommended filenames include BI_YYYY-MM-DD.tif, FWI_YYYY-MM-DD.tif, and WFL_YYYY-MM-DD.tif.
