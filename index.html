Research That Turns Daily Fire Data Into Decisions

The Wildfire Risk and Earth System Laboratory develops operational wildfire danger products and studies how climate, fuels, weather, and human systems shape fire risk. Our website provides a public home for research updates, daily fire danger indices, team information, and collaboration opportunities.

Current Focus

  • Daily wildfire danger monitoring with geospatial index products.
  • Fire-weather interactions under changing climate conditions.
  • Remote sensing and model integration for landscape-scale risk assessment.
  • Reproducible workflows for producing and publishing operational raster datasets.

Featured Data Product

Our fire danger index portal displays daily GeoTIFF layers, including the Burning Index, in an interactive web map. New raster products can be added by copying files into the data folder and regenerating the manifest.

For Partners

The website is designed for routine operations: data producers can update raster files, researchers can add project notes in Markdown, and collaborators can cite stable static pages without needing a database-backed web application.

Publishing Workflow

From Daily GeoTIFF to Public Map

Raw raster files are placed in raw/, converted into web-ready GeoTIFF layers, documented with sidecar JSON metadata, and published as a static website.

  1. PrepareBatch-process raw fire danger rasters.
  2. ValidateRegenerate the manifest and check metadata.
  3. PublishBuild and deploy the static site.

Daily Raster Products

Drop new GeoTIFF files into the data folder, regenerate the manifest, and publish the updated static site.

Transparent Metadata

Sidecar JSON files can document units, bounds, processing versions, notes, and contacts for each layer.

Research Ready
